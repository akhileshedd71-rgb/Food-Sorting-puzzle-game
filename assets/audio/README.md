# Garden Table audio

All nine WAV files are original procedural compositions created for this project.
They use no recordings, third-party samples, or imported compositions. The source
is `generate_audio.py` (Python 3 standard library). Run it to reproduce the assets.

`garden_afternoon.wav` is a seamless eight-bar, 84 BPM loop with soft mallet tones
and a quiet sine pad. `GameAudio` loops the PCM stream and controls music and cues
independently. The eight short effects are select, move, invalid, match, reveal,
serve, win, and click. PCM16 mono, 22,050 Hz; approximately 1.1 MB total.
